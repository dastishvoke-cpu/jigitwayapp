Контекст проекта: Мобильное приложение таксопарка "JigitWay"
1. О проекте и Целевая аудитория
Название продукта: JigitWay
Описание: Мобильное приложение для водителей таксопарка JigitWay (Казахстан), работающих через агрегатор Яндекс.Такси (Yandex Pro). Приложение решает боли водителей по выводу средств и управлению балансом, а также внедряет глубокую систему геймификации для повышения лояльности, удержания (retention) и мотивации водителей работать именно в этом парке.
Целевая аудитория: Водители такси (мужчины, 20-55 лет). Ценят простоту, понятность, прозрачность расчетов и уважительное отношение ("свой пацан", "джигит").

2. Технологический стек
Frontend (Мобильное приложение): Flutter (Dart). Архитектура и стейт-менеджмент будут определены в процессе (рекомендуется Riverpod или BLoC, пока используется setState для MVP).

Backend (API-сервер): Python 3, FastAPI, Uvicorn.

База данных: SQLite (для локальной разработки MVP), в будущем перенос на PostgreSQL.

Деплой / Инфраструктура: VPS сервер (домен: pay.jigitway.kz).

3. Ключевые интеграции
Yandex Fleet API (Диспетчерская):

Синхронизация истории поездок, статусов заказов и текущего баланса водителей.

Используются ключи: Park ID, Client ID, API Key.

Kaspi.kz (Платежный шлюз):

Интеграция для моментальных выплат (payouts) заработанных средств с баланса Яндекс.Про напрямую на карты Kaspi водителей по их запросу из приложения.

СМС-шлюз (в планах): Для авторизации и восстановления паролей (например, SMSC.kz или Mobizon).

4. Геймификация и Экономика (Железная Логика)
Основа удержания водителей — система баллов (XP) и рангов. За успехи водитель получает привилегии (снижение комиссии парка, вывод без комиссии и т.д.).

Базовое правило начисления: 1 успешно завершенная поездка = +10 XP.

Иерархия рангов:

Жолаушы (Путник): 0 — 499 XP (до 50 поездок). Базовые условия.

Сарбаз (Солдат): 500 — 1 999 XP (от 50 поездок).

Шабандоз (Всадник): 2 000 — 4 999 XP (от 200 поездок).

Сұңқар (Сокол): 5 000 — 9 999 XP (от 500 поездок). Элита.

Джигит (Jigit): 10 000+ XP (от 1000 поездок). Легенда парка, VIP-условия.

5. Дизайн-код и UI/UX
Тематика: Dark mode (Темная тема), брутальность, дорогой стиль. Схожесть с игровыми интерфейсами (референс: приложение "Hero's Journey").

Цветовая палитра: Глубокий черный/темно-синий фон (#101010, #0F172A), глянцевые карточки (#1A1A1A), акцентные неоновые цвета: Золотой (#EAB308), Зеленый (#22C55E), Синий (#38BDF8).

Визуал: Использование 2D-иллюстраций автомобилей водителей (например, Toyota Camry в пол-оборота) и аватаров персонажей, соответствующих рангу.

6. Структура экранов приложения (Roadmap)
Экран 1: Авторизация (Auth Screen)
Логика: Вход по номеру телефона и паролю. Регистрация включает SMS-подтверждение (для экономии средств на СМС, при каждом входе используется пароль).

Функции: Восстановление пароля, привязка профиля к базе данных парка в Яндексе.

Экран 2: Главная (Dashboard / Home)
Визуал: Приветствие водителя, крупные карточки статистики.

Элементы:

Общий баланс в тенге (крупно, зеленый градиент).

Количество успешных поездок.

Кнопка "Синхронизировать с Яндексом" (pull-to-refresh или кнопка для ручного вызова API).

Экран 3: Ранги (Ranks / Hero's Journey)
Визуал: Игровой экран прогрессии.

Элементы:

Имя водителя и принадлежность к Клану.

Центральная иллюстрация: 2D-модель машины водителя + персонаж. В будущем — кастомизация авто (спойлеры, диски, номера) за внутреннюю валюту.

Прогресс-бар текущего уровня (неоновая шкала XP).

Интерактивная "Дорожная карта" (RoadMap) или список статусов, показывающий, сколько XP осталось до следующего ранга и какие награды он открывает.

Экран 4: Профиль и Финансы (Profile)
Элементы:

Вывод средств на Kaspi (ввод суммы, расчет комиссии, кнопка "Вывести").

Настройки приложения.

Статистика отмен заказов, штрафы.

Экран 5: Сетевой маркетинг / Рефералы (Referral Tree)
Визуал: Древовидная структура приглашенных водителей.

Логика: Водитель видит "под собой" приглашенных коллег и процент пассивного дохода (бонусы), который он получает с их поездок. Кнопка "Пригласить брата" (генерация реферальной ссылки/кода).

7. Текущий статус разработки
Реализован базовый UI (Главная, Ранги) во Flutter со статической версткой и моковыми запросами.

Реализован базовый API на FastAPI для отдачи статистики (/api/driver/stats) и скачивания заказов из Яндекса (/sync-orders).

Текущая задача ИИ-агентам: Разработка системы авторизации, создание персональных сессий для водителей, привязка реальных данных из базы к конкретному ID/номеру телефона водителя, и доработка UI-компонентов.
